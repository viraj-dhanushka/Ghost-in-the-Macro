# Contributing

Ghost moves the logic in one Excel workbook into a Python module and checks the module against the original workbook, recalculated by LibreOffice. This page covers the four things you are most likely to do.

## Run the tests

```
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/pytest -q
```

You need Python 3.11 or newer. Tests that run the Referee need LibreOffice Calc (see "Install LibreOffice" in the README) and are skipped when it is missing. The full suite takes several minutes; run one file while you work, for example `.venv/bin/pytest tests/test_hostile_shapes.py -q`. Property tests use Hypothesis; where a run needs a seed, use 20261204.

## Add a sample workbook

1. Write a script `samples/make_<name>.py` that builds the workbook with openpyxl and labels it "generated by samples/make_<name>.py". Use `samples/make_discount.py` as the model.
2. Run it to produce the `.xlsx`. Do not commit a workbook you edited by hand: a sample must come from its script.
3. Run `.venv/bin/python -m ghost.cli autopsy samples/<name>.xlsx` and read the output. Anything Ghost cannot convert must appear as "not converted" with a cell and a reason.
4. Add a test next to the existing sample tests that pins what the autopsy reports.

## Add a suspect to the line-up

A suspect is someone else's translation of a sample workbook, written as one self-contained file with a `compute(inputs) -> outputs` function.

1. Put it in `samples/suspects/<workbook>/<name>.py` (`haunted` or `discount`). Start the file with a docstring that says who wrote it, or "Author: not recorded", and what difference it plants.
2. Add its name to the expected list for that workbook in `tests/test_suspects.py`.
3. Run `scripts/ghost-py scripts/lineup.py <workbook>`. It runs every suspect against the Referee and rewrites `samples/suspects/<workbook>/lineup.json` and `samples/suspects/MEASURED.md`. The "Measured result" line in the suspect's docstring must be what that run printed, not what you expect.

## The honesty rule

Every claim Ghost makes comes from something it ran.

- A check that was not run is written as "not checked". A workbook with no Excel-saved values is "not cross-checked against Excel", never a pass.
- A construct Ghost does not convert is listed as "not converted" with the cell and the reason. It is never guessed.
- A pass means the new code matched LibreOffice on the cases that were run. Do not write "correct" or "proven".
- Behaviour changes only with a recorded Decision in `decisions.yaml`. When a workbook contradicts itself, raise a Finding and let a person decide.
- Money uses `decimal.Decimal`, converted from floats with `Decimal(repr(x))`. Worksheet `ROUND` is half away from zero.
- Uploaded workbooks are copied, never modified, and macros are never run from an upload.
- No API keys, tokens or credentials in the repository.
